## Design Principles:

1. **Minimalism First**: Less is more - remove any unnecessary elements
2. **Typography Focus**: Let beautiful typography be the star
3. **Generous Spacing**: White space is your friend - don't crowd elements
4. **Subtle Backgrounds**: Background should support, not compete with content
5. **Simple Icons**: Line-art style only, no complex graphics
6. **Color Restraint**: Use 2-3 colors maximum (blue, teal, white)
7. **Clear Hierarchy**: Title > Tagline > Features > Supporting info
8. **No Distractions**: No team photos, no decorative elements, no complex patterns

---

## Notes for Image Generation:

1. **No Images**: This banner should contain NO team photos or personal images - only text, icons, and design elements.

2. **Minimalistic Approach**: The design should be clean and uncluttered. If in doubt, remove elements rather than add them.

3. **Spacing**: Ensure generous spacing between all elements. The banner should feel breathable, not cramped.

4. **Icons**: Use simple, minimal line-art style icons. Avoid filled icons or complex graphics.

5. **Background**: Keep background very subtle - it should not compete with the content.

6. **Variations**: Consider creating multiple variations with different:
   - Background styles (gradient vs solid)
   - Feature arrangements (vertical list vs grid)
   - Color accents (more blue vs more teal)

7. **File Format**: Request PNG format if you need transparency, or JPG for standard use.

# Panaflex Banner Prompts for Complytics Project

## Banner Specifications
- **Dimensions**: 2 feet x 5 feet (horizontal/landscape orientation)
- **Aspect Ratio**: 2.5:1 (width:height)
- **Resolution**: High resolution (at least 3000x1200 pixels for print quality)
- **Style**: Beautiful, minimalistic, eye-catching

---

## Prompt Option 1: Problem-Solution Focus (Recommended)

### Prompt:

"Create a beautiful, minimalistic horizontal panaflex banner (2 feet x 5 feet, 2.5:1 aspect ratio, 3000x1200px) for Complytics AI-Powered Compliance Management Platform.

**LEFT SECTION (Problem Statement - 30% width):**
Start with a bold problem statement in large, impactful typography:
'Compliance Management: Time-Consuming, Error-Prone, Expensive'

Below it, add supporting text in smaller font:
'Companies struggle with multiple compliance frameworks (GDPR, ISO 27001, SOC 2, HIPAA, PCI DSS, WCAG) simultaneously. Manual compliance checking is slow, costly, and difficult to track.'

Use a darker background section (deep blue #0f172a) with white/light text. Add subtle visual elements like broken chain links, clock icons, or dollar signs to represent the problems.

**CENTER/RIGHT SECTION (Solution - 70% width):**
Display large, bold 'Complytics' title in white/teal gradient text. Below it, tagline: 'AI-Powered Compliance Management Platform'.

Show 5 core features in a clean grid (2 rows, 3 columns or horizontal list):
1. **Compliance Chatbot** - AI-powered RAG system
2. **UI Testing** - Automated accessibility & security
3. **Azure Checker** - Cloud compliance analysis
4. **Schedule Scans** - Automated monitoring
5. **Activity Logs** - Complete audit trail

Each feature with minimal line icon and label. Below features, display supported frameworks: 'GDPR • ISO 27001 • SOC 2 • HIPAA • PCI DSS • WCAG'.

**DESIGN STYLE:**
- Minimalistic with generous spacing
- Gradient background: deep blue (#1e3a8a) transitioning to teal (#06b6d4)
- Clean typography hierarchy
- Simple line-art icons
- Visual divider between problem and solution sections
- Eye-catching but professional
- High contrast for visibility from distance

**COLORS:**
- Problem section: Dark blue (#0f172a) background, white/red accent text
- Solution section: Blue-to-teal gradient, white text
- Icons: Teal/cyan (#06b6d4) or white
- Text: White for readability

The banner should be eye-catching from a distance, clearly communicate the problem and solution, and maintain a professional, minimalistic aesthetic."

## Design Guidelines for All Prompts:

### Color Palette:
- **Problem Section**: Dark blue (#0f172a or #1e3a8a)
- **Solution Section**: Gradient from deep blue (#1e3a8a) to teal (#06b6d4)
- **Text**: White (#ffffff) for maximum contrast
- **Accents**: Teal/cyan (#06b6d4) for icons and highlights
- **Problem Accents**: Subtle red/orange for warnings (optional)

### Typography:
- **Headings**: Bold, large, sans-serif (extra large for titles)
- **Body Text**: Medium-weight, readable
- **Features**: Medium-weight with small icons
- **Frameworks**: Small, subtle text
- **Hierarchy**: Clear size differentiation

### Visual Elements:
- **Icons**: Minimal line-art style only
- **Background**: Subtle gradient or solid with texture
- **Spacing**: Generous white space
- **Contrast**: High contrast for outdoor visibility
- **No Complex Graphics**: Keep it simple and clean

### Key Requirements:
1. **Problem Statement First**: Always start with the compliance challenge
2. **Clear Solution**: Complytics as the answer
3. **5 Core Features**: Always include all features
4. **Frameworks**: Display supported frameworks
5. **Minimalistic**: Clean, uncluttered design
6. **Eye-Catching**: High contrast, bold typography
7. **Professional**: Suitable for business/presentation use

---

## Notes:

1. **Print Quality**: Ensure 300 DPI resolution for print (3000x1200px minimum)
2. **Outdoor Visibility**: Use high contrast colors and large, bold text
3. **Readability**: Test that text is readable from 10-15 feet away
4. **Brand Consistency**: Maintain Complytics brand colors (blue, teal, white)
5. **Variations**: Create multiple versions to test which works best
6. **File Format**: PNG for transparency, JPG for standard use
